🖼️ TinyPixel Privacy Policy

Effective Date: November 3, 2026

In short: TinyPixel collects no personal data and shows no ads. Your images and screenshots stay on your Mac. It goes online for one thing: a once-a-day check for a newer version, which you can switch off, and the download of an update only if you choose to install it.

1. Overview

OsiVibeCode LLC, an Arizona limited liability company, publishes TinyPixel, a macOS app for taking screenshots and editing images. This policy explains what the app stores and what it does not. There is no account, no sign-in, no analytics and no advertising.

2. Data Stored Locally

TinyPixel keeps its settings in its sandbox container, at ~/Library/Containers/com.osivibecode.tinypixel/. They are never transmitted anywhere:

  • Preferences: theme, language, keyboard shortcuts, capture delay, what happens after a capture, and whether the menu bar icon shows.
  • Screenshot saving: your file format, quality and file name pattern, and a bookmark to the save folder you chose.
  • Last capture area: its position on screen, so Return can repeat it.
  • Tool settings: your last brush, colour and other tool options.
  • Update check: when it last ran, and the last update it offered you.
  • Latest crash summary: described in section 4.

3. Update Checks

About once a day, TinyPixel reads a signed update feed at osivibecode.github.io to see whether a newer version has been published. If there is one, it tells you. When you choose to install it, TinyPixel downloads the new version from github.com, checks its signature, and installs it.

  • What is sent: ordinary web requests, for the feed and, if you install an update, for its download. They name the app and its version. No identifier, no system profile and nothing about your images is included.
  • Who sees it: GitHub, which hosts the feed and the releases, receives your IP address as it would for any web request. We do not receive or keep these logs. GitHub's use of data is covered by the GitHub Privacy Statement.
  • Turning it off: TinyPixel ▸ About ▸ Updates ▸ "Check for updates automatically". With it off, TinyPixel connects only when you choose Check for Updates….

A version of TinyPixel from the Mac App Store has no update check and makes no network connections; the App Store handles its updates.

4. Crash Details

After a crash, macOS may give TinyPixel a diagnostic report through Apple's MetricKit framework. TinyPixel keeps a short summary of the latest one on your Mac: the date, the app version and build, the error codes, and the top of the crashed thread's call stack, as program names and memory offsets. It contains no images and no file paths.

The summary is not sent automatically. If the crash happened in the last 30 days, Report an issue in TinyPixel ▸ About adds it to a draft email, along with your TinyPixel and macOS versions. You can read or delete it before sending, and we receive it only if you send that email.

Separately, if you choose to share analytics with app developers in macOS, Apple may give us anonymised crash reports for versions from the Mac App Store or TestFlight. You control this in System Settings ▸ Privacy & Security ▸ Analytics & Improvements.

5. Your Images and Screenshots

TinyPixel opens, edits and saves images on your Mac. It never uploads them and has no servers to upload them to. Recognize Text and Select Text run on your Mac with Apple's Vision framework. Screenshots go only where you send them: the preview, the clipboard, an editing window, or your save folder.

6. Third-Party Services

TinyPixel contains no advertising SDK, no analytics library and no third-party crash reporter. The only outside services it contacts are GitHub and GitHub Pages, for the updates in section 3. If you email us, your email provider and ours handle that message.

7. Required Permissions

  • Screen Recording — macOS requires this so TinyPixel can capture the screen. It is used only when you take a screenshot, and captures are not transmitted.
  • File access — TinyPixel runs inside the macOS App Sandbox and can reach only the files you open or save and the save folder you choose.
  • Network — outgoing connections only, for the update check and, if you install an update, its download.
  • Start at login — optional, so the shortcuts are ready when you log in. Managed by macOS in System Settings ▸ General ▸ Login Items.

8. Data Retention & Deletion

Everything TinyPixel stores is on your Mac, so we have no access to it and nothing to delete on our side. If you email us, we keep your message for as long as we need it to answer you and will delete it on request. To remove everything from your Mac, quit TinyPixel, move it to the Trash and delete the container folder in section 2. You can revoke Screen Recording in System Settings ▸ Privacy & Security.

9. Children's Privacy

TinyPixel is a general-purpose desktop app, is not directed at children and collects no personal data from anyone.

10. Changes to This Policy

If a future version of TinyPixel ever collects anything, this page will be updated before that version ships, and the change will be described in the app's release notes.
